First baseline uses original slice[7] bit 14 clear. See 469-vdec-direct-baseline-perf.txt.
Temporary matrix uses the cacheable allocations and scalar P010 path. Each check decodes 240 frames.
PXP and SMMU IRQ fields list the cumulative counts before and after each run.
4: slice[7] bit 14 on B slices only.
256: slice[7] bit 14 on every I/P/B slice (both test SPSes have direct_8x8_inference_flag=1).
5: 4 + pub[3] bit 14. 6: 4 + both inverse L0 entries. 7: both changes.
12: 4 + alternative frame reference field nibble. This rejected setting triggered SMMU faults.
20: 4 + second ColMV address. 36: 4 + pub[21]. 68: 4 + flip spatial flag.
132: 4 + normalize POCs. 260: 256 + 4. 516: 4 + clear inverse L0 table.
31: 4 + pub[3] bit 14 + both inverse L0 entries + alternative field nibble + second ColMV address.
